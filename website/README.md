# Website Dietmar Koop Steuerberatung

Statische Seite, keine Datenbank, keine Fremdanbieter. Öffnen: `index.html` im Browser oder lokal mit `python3 -m http.server` im Ordner `website`.

- `index.html` – Startseite (Leistungen, Bau, Mandanten, Ablauf, Team, Kontakt)
- `impressum.html`, `datenschutz.html` – Rechtstexte (vor Livegang ergänzen, siehe HTML-Kommentare)
- `assets/site.css`, `assets/site.js` – Gestaltung, Scroll-Animationen und Helfer (Fristenrechner, Bürozeiten, Menü, Formular)
- `assets/img/` – Fotos (WebP). Stadtfotos von Wikimedia Commons, Nachweis im Fuß der Seite und im Impressum
- `assets/fonts/` – Newsreader und Hanken Grotesk, selbst gehostet (SIL Open Font License)

Icons: Lucide (ISC-Lizenz), als Inline-SVG eingebettet.
